# Prompt de diseño para Figma — Portafolio / Galería digital de artista

Diseña una experiencia web completa para el portafolio personal de **Diego Patiño**, artista multidisciplinario y tatuador radicado en Medellín, Colombia.

El proyecto debe funcionar inicialmente como una **galería personal y portafolio profesional**, pero su arquitectura visual debe permitir que, en el futuro, pueda evolucionar hacia una plataforma donde otros artistas también puedan tener su propio espacio.

La web **no debe sentirse como una red social, un feed de Instagram ni un sitio corporativo genérico**. Debe sentirse como una mezcla entre:

* Galería de arte contemporáneo.
* Archivo personal.
* Portafolio editorial.
* Estudio creativo.
* Tienda de objetos y obra.

La interfaz debe ser limpia, sobria, minimalista y funcional. No reinventar patrones de navegación innecesariamente. La prioridad es que **la obra sea la protagonista**.

---

# 1. CONCEPTO GENERAL

La idea central es crear un espacio digital donde el trabajo artístico pueda ser explorado con más profundidad que en una red social.

Instagram funciona principalmente como un canal de descubrimiento y atracción de audiencia.

Esta web funciona como el destino final donde una persona puede:

* Conocer al artista.
* Explorar su trabajo.
* Descubrir proyectos y colecciones.
* Ver el recorrido creativo.
* Acceder al archivo histórico.
* Conocer novedades.
* Comprar prints, ropa y merchandising.
* Contactar al artista.
* Encontrar la ubicación del estudio.

La experiencia debe sentirse como visitar un **estudio, exposición y archivo digital personal**.

No utilizar:

* Feed infinito.
* Likes.
* Contadores de seguidores.
* Comentarios.
* Elementos típicos de redes sociales.
* Dashboards.
* Cards excesivamente redondeadas.
* Gradientes tecnológicos.
* Estética SaaS.
* Animaciones innecesarias.
* Interfaces recargadas.

La dirección visual debe ser más cercana a un **sitio editorial de arte contemporáneo**.

---

# 2. PERSONALIDAD VISUAL

El diseño debe transmitir:

* Minimalismo.
* Intención.
* Curaduría.
* Personalidad artística.
* Profesionalismo.
* Calma visual.
* Espacio.
* Archivo.
* Materialidad.
* Diseño editorial.

La interfaz debe funcionar como el marco de una exposición.

**La web no debe competir visualmente con las obras.**

Utilizar:

* Mucho espacio negativo.
* Tipografía con buen espaciado entre letras.
* Líneas finas.
* Bordes sutiles.
* Composiciones asimétricas cuando tenga sentido.
* Fotografías grandes.
* Imágenes a pantalla completa en momentos importantes.
* Jerarquías tipográficas claras.
* Diseño basado en grid editorial.

Evitar que todo se vea perfectamente simétrico o como una plantilla genérica.

NOVEDADES
TIENDA

La navegación debe tener:

* Altura generosa.
* Mucho espacio horizontal.
* Tipografía pequeña.
* Letras en mayúscula.

* Bordes muy sutiles.

Debe sentirse refinada y funcional.

En dispositivos móviles, transformar la navegación en un menú minimalista, evitando interfaces pesadas.

# 4. HOME / LANDING PAGE

La home debe ser relativamente sencilla. No crear una landing gigante con veinte secciones.

Debe funcionar como una introducción al universo creativo del artista.

## SECCIÓN 1 — HERO

Pantalla inicial con una fotografía principal fuerte.

Puede ser:

* Retrato del artista.
* El artista trabajando.
* Una fotografía del estudio.
* Una imagen artística relacionada con su trabajo.

La fotografía debe ocupar gran parte de la pantalla.

Sobre la imagen o integrada a la composición:

DIEGO PATIÑO

ARTIST · TATTOOER · MEDELLÍN, COLOMBIA

La información debe ser discreta.

La fotografía debe ser la protagonista.

Incluir un pequeño indicador de scroll.

---

## SECCIÓN 2 — INTRODUCCIÓN

Una sección editorial sencilla.

Título:

ABOUT

Texto breve sobre Diego.

Debe explicar que es un artista y tatuador de Medellín, con un enfoque multidisciplinario y un interés por explorar diferentes medios, ideas y proyectos.

No escribir una biografía completa.

Debe sentirse como una introducción personal.

Incluir:

→ CONOCER MI RECORRIDO

La composición puede utilizar una fotografía secundaria o simplemente texto con mucho espacio negativo.

* Grid editorial.
* Imágenes de diferentes tamaños.
* Una pieza grande acompañada de varias pequeñas.
* Espacios amplios entre obras.

Título
Año
Categoría

2026

La galería representa el trabajo curado y profesional del artista.

Aquí solo deben aparecer las obras que Diego quiere presentar como parte de su portafolio actual.

No es un archivo completo.

Debe existir un sistema de filtros.

Ejemplo:

ALL
TATTOO
ART
ILLUSTRATION
DESIGN
PROJECTS

La galería debe sentirse como recorrer una exposición.

Explorar varias alternativas visuales:

### Opción principal

Algunas imágenes grandes.

Algunas verticales.

Algunas horizontales.

Evitar que todas tengan exactamente el mismo tamaño.

La navegación debe sentirse fluida y limpia.

Cada obra debe abrir su propia página.

# 14. SISTEMA DE DISEÑO

Crear un pequeño sistema de diseño reutilizable.

Definir:

## TIPOGRAFÍA

Utilizar una combinación editorial.

Una fuente sans-serif limpia para navegación e información funcional.

Opcionalmente una fuente serif o display para titulares.

Ejemplo conceptual:

Sans-serif:

* Navegación.
* Metadatos.
* Botones.
* Información técnica.

Serif / Display:

* Titulares.
* Textos importantes.
* Elementos editoriales.

La tipografía debe sentirse contemporánea y atemporal.

No usar fuentes excesivamente futuristas.

---

## COLORES

Mantener una paleta limitada.

Base:

OFF-WHITE / WARM WHITE

BLACK / CHARCOAL

GRAY

Un único color de acento.

El color de acento debe utilizarse para:

* Estado activo.
* Hover.
* Detalles pequeños.
* Líneas.
* Indicadores.

No utilizar muchos colores de interfaz.

Las obras ya aportarán color y personalidad.

---

## GRID

Utilizar un grid editorial consistente.

Mucho espacio negativo.

Márgenes generosos.

Separaciones claras.

La composición puede romper el grid ocasionalmente para dar personalidad, pero nunca de forma caótica.

---

# 15. INTERACCIONES Y ANIMACIONES

Las animaciones deben ser discretas.

Utilizar:

* Fade.
* Desplazamientos suaves.
* Hover sobre obras.
* Transiciones entre páginas.
* Aparición progresiva de imágenes.

Evitar:

* Scroll hijacking.
* Animaciones largas.
* Efectos 3D innecesarios.
* Partículas.
* Cursores extravagantes.
* WebGL sin propósito.

La experiencia debe sentirse rápida.

---

# 16. RESPONSIVE DESIGN

Diseñar primero una experiencia desktop completa.

Luego crear versiones para:

* Tablet.
* Mobile.

En mobile:

* Menú compacto.
* Grid adaptado.
* Fotografías grandes.
* Navegación fácil con una mano.
* Formularios simples.
* Tienda completamente funcional.

No simplemente reducir el diseño de escritorio.

Reorganizar las composiciones cuando sea necesario.

# DIRECCIÓN FINAL

El resultado debe sentirse como una combinación de:

**GALERÍA DE ARTE + ARCHIVO PERSONAL + PORTAFOLIO EDITORIAL + ESTUDIO CREATIVO + TIENDA DE ARTISTA**

La interfaz debe ser sencilla.

La navegación debe ser familiar.

La tecnología debe desaparecer.

El contenido y la obra deben ocupar el centro de la experiencia.

No diseñar una red social.

No diseñar una aplicación SaaS.

No diseñar una tienda genérica.

Diseñar un espacio digital que se sienta como entrar al universo creativo de un artista y poder recorrerlo libremente.
