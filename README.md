# Portfolio / Tattoo Gallery

Sitio web personal diseñado como galería y portafolio para mostrar mi trabajo como tatuador, presentar mi estilo artístico y facilitar el contacto con nuevos clientes.

## Características

* Galería de tatuajes y proyectos realizados
* Portafolio organizado por estilos o categorías
* Sistema o enlace para agendar citas
* Tienda para vender productos, prints y merch
* Información sobre el artista
* Información del estudio y ubicación
* Enlaces a redes sociales
* Diseño responsive para dispositivos móviles y escritorio

## Secciones

### Inicio

Presentación visual de la marca, el artista y una selección destacada del trabajo.

### Galería

Espacio para explorar los tatuajes, diseños y proyectos realizados.

### Agenda

Sección destinada a facilitar el proceso de reserva de citas y consultas para nuevos tatuajes.

### Tienda

Tienda para la venta de:

* Merch
* Prints
* Productos de la marca
* Otros artículos y proyectos

### Sobre mí

Información sobre mi trayectoria, estilo, enfoque artístico y filosofía de trabajo.

### Contacto

Enlaces directos para التواصل con el estudio, redes sociales y otros canales de contacto.

## Objetivo

Crear una plataforma que funcione como punto central de mi presencia digital, permitiendo que cualquier persona pueda conocer mi trabajo, explorar mi portafolio, agendar una cita o comprar productos desde un solo lugar.

## Estado del proyecto
